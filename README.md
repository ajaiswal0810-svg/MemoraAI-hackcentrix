# MemoraAI
MemoraAI is an AI-powered study companion designed to help students turn scattered notes, PDFs, and links into structured summaries, flashcards, and personalized revision paths.

## Problem
Students struggle with information overload and inefficient revision using scattered resources.

## Solution
MemoraAI centralizes learning materials and uses AI to create exam-ready, personalized study experiences.

## 🚀 Live Demo

- **Live MVP (Deployed Prototype):** https://memoraai.lovable.app
- **Demo Video:** Coming soon (before final judging)

## Features
- AI-powered summaries (prototype)
- Smart flashcards
- Personalized revision paths
- Progress tracking dashboard
